# 解像度の候補を増やす（4:3・3:2・iPhone Duo の比率、縦長）

## 背景
固定の解像度の候補が 16:9 と 16:10 中心で、4:3 は小さいもの（1024×768）しかない。iPhone Duo を開いて
横向きにした内側の画面は約 1.42:1（2853×2007）で 4:3 に近く、いまの候補では上下か左右に大きな
余白が出る。縦向きで使う候補もない。

## 現状の挙動
解像度を選べる場所は 4 つあり、どれも同じ候補が並ぶ。

- 設定 → 表示 → 解像度
- 接続先の編集 → 解像度
- セッションのメニュー → 解像度（そのセッションの間だけ）
- Mac 版のメニュー

候補は「自動（画面に合わせる）」と、次の 13 種類（すべて横長、小さい順）。

1024×768（4:3）、1280×720（16:9）、1280×800（16:10）、1280×1024（5:4）、1366×768（16:9）、1440×900（16:10）、
1600×900（16:9）、1680×1050（16:10）、1920×1080（16:9）、1920×1200（16:10）、2560×1440（16:9）、
2560×1600（16:10）、3840×2160（16:9）

## 変更後の挙動
4 つの場所すべてで、候補が次のようになる。並びは「自動」のあとに **横長** と **縦長** の見出しで分け、
それぞれ小さい順。既存の 13 種類はそのまま残す（すでに選んでいる接続先の設定は変わらない）。

### 横長（既存 13 種類に、次の 11 種類を足す）
| 解像度 | 表示名 | 比率 |
|---|---|---|
| 1600×1200 | 1600×1200（4:3） | 4:3 |
| 1920×1352 | 1920×1352（iPhone Duo） | 約 1.42:1 |
| 2034×1398 | 2034×1398（iPhone Duo 外側） | 約 1.45:1 |
| 2048×1536 | 2048×1536（4:3） | 4:3 |
| 2160×1440 | 2160×1440（3:2） | 3:2 |
| 2272×1600 | 2272×1600（iPhone Duo） | 約 1.42:1 |
| 2560×1800 | 2560×1800（iPhone Duo） | 約 1.42:1 |
| 2560×1920 | 2560×1920（4:3） | 4:3 |
| 2848×2004 | 2848×2004（iPhone Duo） | 約 1.42:1（内側の画面とほぼ同じ画素数） |
| 2880×1920 | 2880×1920（3:2） | 3:2 |
| 2880×2160 | 2880×2160（4:3） | 4:3 |

### 縦長（新しく足す 11 種類を縦にしたもの）
1200×1600（3:4）、1352×1920（iPhone Duo 縦）、1398×2034（iPhone Duo 外側 縦）、1536×2048（3:4）、
1440×2160（2:3）、1600×2272（iPhone Duo 縦）、1800×2560（iPhone Duo 縦）、1920×2560（3:4）、
2004×2848（iPhone Duo 縦）、1920×2880（2:3）、2160×2880（3:4）

### 見え方
- 選んだ解像度は、これまでと同じく端末の向きに関係なくその大きさで頼む（縦長を選んで横向きにすれば左右に余白が出る）
- 足した 22 種類は、接続したときに Mac（macos-rdp-server）側で Retina（文字がくっきりした表示）になることを確認済み
  （拡大率 300%、2026-10-25、この Mac で。iPhone Duo の内側 2848×2004 は Mac 側で 1424×1002 ポイント）
  - 補足: 既存の 1024×768・1280×1024 は Mac 側で Retina にならず等倍になる（これまでどおり。今回は変えない）
  - 補足: 接続中にメニューで別の大きさへ切り替えたときは、macOS が Retina を使わせない組み合わせがあり、その場合は等倍で出る（サーバ側の既知の制約）

## スコープ外
- 解像度を自由に入力できるようにすること
- 端末の向きに合わせて縦横を自動で入れ替えること
- 「自動（画面に合わせる）」の動き
- 既存の候補の削除や表示名の変更
- 解像度の選択を接続先ごとに覚えること（接続先の編集で選ぶ、これまでどおり）

## E2E テストチェックリスト
- ### 正常系
  - [ ] 設定・接続先の編集・セッションのメニューの 3 か所（Mac 版はメニューも）に、横長 24 種類・縦長 11 種類が見出しつきで並ぶ
  - [ ] 接続先の編集で 2848×2004（iPhone Duo）を選んでつなぐと、Mac に 2848×2004 の Retina の仮想ディスプレイができ、アプリでは「画面に合わせる」で四隅まで正しい縦横比で映る
  - [ ] 縦長の 1352×1920（iPhone Duo 縦）でつなぐと、Mac に 1352×1920 の Retina の仮想ディスプレイができる
  - [ ] セッションのメニューで 2048×1536（4:3）に切り替えると、Mac 側が 2048×1536 になる
- ### 異常系
  - [ ] Windows など表示制御チャネルのないサーバでは、これまでどおり最初に頼んだ大きさのまま（候補を変えても落ちない）
- ### エッジケース
  - [ ] 以前に既存の候補（例: 3840×2160）を選んでいた接続先は、アップデート後も同じ解像度で、編集画面でもその候補が選ばれている
  - [ ] 縦長を選んだまま端末を横向きにすると、左右に余白が出るだけで、タップの位置はずれない
  - [ ] 候補の一覧が長くても、セッションのメニュー（半分の高さのシート）から最後の候補まで選べる
