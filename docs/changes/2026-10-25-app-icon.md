# アプリアイコンを付ける

## 背景
mRemote にはアプリアイコンが設定されていない。iPhone Duo のホーム画面・App ライブラリ・Spotlight・
設定アプリでは iOS 標準の空白（白地に格子）のアイコンになり、ほかのアプリの中から探しにくい。

## 現状の挙動
- ホーム画面・App ライブラリ・Spotlight の検索結果・設定アプリの一覧で、標準の空白のアイコンが出る
- Mac Catalyst 版も、Dock と Finder では標準の空白のアイコン
- 上流（mikuta0407/mRemote）にもアイコンはまだない

## 変更後の挙動
- アプリアイコンが付く。iPhone Duo のホーム画面・App ライブラリ・Spotlight・設定アプリ・アプリの切り替え画面で同じアイコンが出る
- Liquid Glass に対応したアイコン（Icon Composer の形式）にする。ホーム画面の表示の設定（ライト・ダーク・
  色付き（ティント）・クリア）に、iOS が自動で合わせる
- 絵柄は「開いた iPhone Duo」（比較ページの案 F6「白地に青」。2026-10-25 にユーザーが選択）
  - 白地（下へ向かってごく薄い青みがかった灰色）の中央に、横向きに開いた Duo を大きく描く
  - Duo の枠は青。真ん中の折り目で枠が左右に分かれ、画面にも折り目の線が通る。右の画面の上に内側カメラの点
  - 画面は紺。離れたデスクトップの窓が 2 枚、斜めに重なって映っている（右上の奥の窓は半透明、左下の手前の窓は白）
  - Mac・マウスポインタ・Dock は描かない
- ホーム画面の表示ごとの見え方
  - ライト: 上のとおり
  - ダーク: 背景が灰色になる（白地を暗くしたもの）。Duo の青い枠と紺の画面はそのまま
  - 色付き・クリア: iOS が全体を塗り替える（形だけが残る）
- 選ぶまでに作った案（モニターとポインタ・「m」・Duo と Mac など）は入れない
- Mac Catalyst 版の Dock・Finder にも同じアイコンが出る
- アイコン以外（アプリ名・画面の中身）は変わらない

## スコープ外
- アプリ名（ホーム画面の「mRemote」）の変更
- アプリの中の画面にロゴを出すこと（起動画面・設定の「情報」など）
- ユーザーが選べる別のアイコン（代替アイコン）
- 上流へ送ること（フォークの中だけで入れる）

## E2E テストチェックリスト
- ### 正常系
  - [ ] iPhone Duo 実機のホーム画面に、選んだアイコンが出る（空白のアイコンではない）
  - [ ] 実機の App ライブラリ・Spotlight の検索結果・設定アプリの一覧にも同じアイコンが出る
  - [ ] ホーム画面をダークにしても、絵柄が背景に埋もれず見分けられる
  - [ ] ホーム画面を色付き（ティント）・クリアにしても、絵柄の形が分かる
  - [ ] Mac Catalyst 版のビルドで、Dock に同じアイコンが出る
- ### 異常系
  - [ ] すでに空白のアイコンで入っている実機に上書きで入れても、アイコンが新しいものに変わる（必要なら再起動して確かめる）
- ### エッジケース
  - [ ] 小さい表示（Spotlight・設定アプリの一覧の大きさ）でも絵柄がつぶれず、何のアプリか分かる
  - [ ] Duo を閉じた状態（外側の画面）と開いた状態（内側の画面）の両方のホーム画面で、アイコンが正しく出る
  - [ ] 既存の E2E（smoke）が通る（アイコンを足したことでビルドやテストが壊れていない）
