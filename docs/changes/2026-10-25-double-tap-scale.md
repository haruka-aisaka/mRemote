# ダブルタップで切り替えた表示倍率を、セッションの表示倍率として扱う

## 背景
「接続し直すと拡大率が 100% に戻る」という報告を調べたところ、二つのことがわかった。

1. 実機の設定で「初期倍率」が「100%」になっていた。一覧から開き直したセッションは毎回この設定で始まるので、
   100% に戻るのは設定どおりの動作（設定を「画面に合わせる」にすれば直る）。
2. それとは別に、ダブルタップで切り替えた表示倍率が、画面の中だけで切り替わり、セッションの表示倍率
   （メニューの「表示倍率」）には反映されていなかった。

## 現状の挙動
「画面のタッチ」が「表示の移動だけ」のとき、デスクトップをダブルタップすると「画面に合わせる」⇄「100%」が切り替わる。

- メニューの「表示倍率」は切り替える前のまま
- メニューを開け閉めするなど、画面が描き直されるときに、切り替える前の倍率に戻ってしまう

## 変更後の挙動
ダブルタップで切り替えた倍率が、そのセッションの表示倍率になる。

- メニューの「表示倍率」も切り替えた方を表示する
- 画面が描き直されても、切り替えた倍率のまま
- 保存はしない（これまでどおり、セッションの間だけ。次に一覧から開くと「初期倍率」で始まる）

## スコープ外
- 開き直したときに前回の表示倍率を引き継ぐこと（今は「初期倍率」で始まる。変えるなら別に相談）
- 「表示の移動だけ」以外のタッチモードでのダブルタップ（ダブルクリックとして Mac/Windows へ送る。変えない）
- ピンチでの拡大（表示倍率とは別の、その場の拡大）

## E2E テストチェックリスト
`e2e/mac-host/e2e.ts`（シミュレータ → この Mac のテスト用サーバ）で確かめる。

- ### 正常系
  - [x] ダブルタップで 100% になる（zoom-toggle）
  - [x] そのときメニューの表示倍率が「100%」（zoom-toggle）
  - [x] メニューを閉じて画面が描き直されても 100% のまま（zoom-toggle）
  - [x] もう一度ダブルタップすると「画面に合わせる」に戻る（zoom-toggle）
- ### 異常系
  - [x] 「タッチした場所を操作」ではダブルタップが倍率を変えず、Mac でのクリックになる（tap・reopen の前提）
- ### エッジケース
  - [x] 100% にしてから切断し、一覧から開き直すと「初期倍率」（画面に合わせる）で始まる（reopen）
