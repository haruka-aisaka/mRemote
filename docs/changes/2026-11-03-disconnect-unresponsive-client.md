# 応答しなくなった iPhone の接続を Mac 側で 20 分後に切る

## 背景

mRemote で Mac につないだまま iPhone をホームに戻したりロックしたりすると、アプリは iOS に止められ、Mac とやり取りできなくなる。それでも Mac 側のサーバは接続を切らずに抱え続ける。アプリが iOS に落とされた場合や圏外になった場合も同じで、1 時間以上残っていたことがある（2026-10-25 に確認）。

その間、Mac は次の状態のまま戻らない。

- 専用の仮想ディスプレイがメインの画面のまま残る
- 画面の取り込みとエンコードが続く
- 別の接続（E2E テストなど）が「使用中」として止められる

iPhone から応答がない状態が長く続いたら、Mac 側で接続を片付けたい。

## 現状の挙動

- mRemote が前面にいる間は、普通に使える。
- ホームに戻した・ロックした場合: アプリは数秒で iOS に止められる。Mac 側の接続は切れずに残る。
  - 戻ってくれば、そのまま続きから使える（2026-11-03 の修正で、表示もすぐ戻る）。
- アプリが iOS に落とされた・電源が切れた・圏外になった場合も、Mac 側の接続は残り続ける。
  - 次にアプリを開くと新しい接続になる。古い接続は、新しい接続が来るか通信が切れたと分かるまで残る。
- 接続が切れたときにアプリに戻ると、「自動再接続」の設定（接続先ごと、またはアプリ全体）に従う。オンなら自動でつなぎ直し、オフなら切れた状態で再接続ボタンを待つ。
  - ただし、つながったあとで通信が切れた場合（Mac 側が接続を閉じた場合を含む）は「接続を拒否されました」と表示され、自動では再接続しない（実装時に判明）。自動で再接続するのは、ネットワークに到達できない・時間切れなどと分類された場合だけ。

## 変更後の挙動

### Mac 側（サーバ）

- mRemote から接続している間、アプリと Mac とのやり取りが **20 分** 途切れたら、Mac 側がその接続を切る。
  - 「やり取りが途切れる」のは、アプリが Mac と通信できない状態のとき。ホームに戻した、ロックした、アプリが落ちた、電源が切れた、圏外になった、などが当てはまる。
  - アプリを前面に出している間は、何も操作していなくても切らない。
- 切ったあとは、今の切断と同じ扱いにする。専用の仮想ディスプレイは再接続を待って 5 分（`RDP_VIRTUAL_DISPLAY_KEEP`）残し、その後に片付ける。
- 20 分という時間は、サーバの設定（LaunchAgent の plist の環境変数）で変えられる。0 にすると切らない（今と同じ）。
- 切った理由はサーバのログに残す（「mRemote から 20 分応答がないため切断」）。

### iPhone 側（mRemote）

- 20 分以内に戻った場合: 今と同じく、そのまま続きから使える。
- 20 分を過ぎて戻った場合: 接続は Mac 側で切られている。ほかの理由で切れたときと同じく、「自動再接続」の設定に従う。
  - オン（既定）なら、戻るとすぐ自動でつなぎ直す。表示は今の再接続と同じ（「再接続中…」の表示のあと、つながる）。
  - オフなら、切れた状態の表示になり、再接続ボタンでつなぎ直す。
- このため、つながったあとで通信が切れた場合は、「接続を拒否されました」ではなく、ネットワークの切断（自動再接続の対象）として扱う。Mac 側が切った場合に限らず、接続中に通信が切れたとき全般に当てはまる。つなぐ前の失敗（Mac 側で待ち受けていない、など）は今どおり「接続を拒否されました」。
- 画面の見た目や設定画面は変えない。

## スコープ外

- mRemote 以外のクライアント（Windows App、mstsc、FreeRDP など）からの接続。Mac 側の新しい仕組みに対応していないので、今どおり切らない。
- アプリを前面に出したまま操作しない状態での切断（無操作タイムアウト）。
- アプリの設定画面に時間の項目を足すこと。
- SSH の接続。
- 仮想ディスプレイを残しておく時間（`RDP_VIRTUAL_DISPLAY_KEEP`）の既定値。
- 20 分以内に戻ったときの挙動。

## E2E テストチェックリスト

- ### 正常系
  - [ ] mRemote を前面に出したまま 20 分以上操作しなくても、接続は切れない
  - [ ] ホームに戻して 20 分以内に戻ると、そのまま続きから使える（表示も操作も効く）
  - [ ] ホームに戻して 20 分を過ぎると、Mac 側のログに「応答がないため切断」が出て、接続が切れる
  - [ ] その後アプリに戻ると、自動再接続（オン）で再びつながり、表示も操作も効く
  - [ ] 切断から 5 分後に、Mac の仮想ディスプレイが片付く
- ### 異常系
  - [ ] 接続中に mRemote を強制終了すると、遅くとも 20 分後に Mac 側で接続が切れる
  - [ ] 接続中に iPhone を圏外（機内モード）にすると、遅くとも 20 分後に Mac 側で接続が切れる（通信の失敗で先に切れることもある）
  - [ ] 自動再接続がオフの接続先では、20 分を過ぎて戻ると切れた状態の表示になり、再接続ボタンでつながる
- ### エッジケース
  - [ ] サーバの設定で時間を短くする（例: 2 分）と、その時間で切れる
  - [ ] サーバの設定で 0 にすると、何分たっても切れない
  - [ ] mRemote 以外のクライアント（FreeRDP）でつないでいると、通信がなくても切れない
  - [ ] 時間ぎりぎりで戻った場合（切られる直前・直後）も、続きから使えるか自動再接続でつながる。どちらでも固まらない
  - [ ] 切られた後、別のクライアントや E2E テストが「使用中」で止められない
