# 表示倍率を接続先ごとに覚え、次に開いたときもその倍率で始める

## 背景
一覧から接続を開き直すたびに、表示倍率が設定の「初期倍率」に戻る。Mac は「100%」、Windows は
「画面に合わせる」のように接続先ごとに見やすい倍率が違うので、毎回メニューやダブルタップで
切り替え直すのが手間になっている。

## 現状の挙動
- 新しく開いたセッションは、設定（設定 → 表示 → 初期倍率）の「画面に合わせる」か「100%」で始まる
- セッションの中では、メニューの「表示倍率」か、ダブルタップ（画面のタッチが「表示の移動だけ」のとき）で切り替えられる
- 切り替えた倍率はそのセッションの間だけ。切断して一覧から開き直すと、初期倍率に戻る
- 「接続先一覧へ戻る（接続を維持）」で一覧に戻り、また開いた場合は、同じセッションなので倍率はそのまま

## 変更後の挙動
- 表示倍率を変えると、その接続先の倍率として覚える。変え方は問わない（メニューの「表示倍率」・ダブルタップ）
  - 変えた時点で覚える。切断のしかた（メニューから切断・アプリの終了・通信が切れたまま閉じる）に関係なく残る
- 一覧から接続先を開くと、その接続先で最後に使った倍率で始まる
- アプリを終了して起動し直しても覚えている
- まだ一度も倍率を変えていない接続先は「画面に合わせる」で始まる
- 設定の「初期倍率」はなくなる（設定 → 表示 からこの項目が消える）
  - これまで「100%」にしていた場合も、各接続先の最初の 1 回は「画面に合わせる」で始まり、変えればそれ以降はその倍率になる
- 覚えるのは「画面に合わせる」か「100%」かだけ。ピンチで拡大した量や表示の位置は覚えない（これまでどおり開くたびに戻る）
- 接続先を複製すると、覚えていた倍率も複製先に引き継ぐ
- 接続先を削除すると、覚えていた倍率も消える
- 覚えた倍率はこの端末の中だけに残す（.rdp ファイルの読み込みなどには関係しない）

## スコープ外
- ピンチでの拡大量・表示位置を覚えること
- 「Windows の拡大率」や、メニューで一時的に変えた「解像度」を覚えること（これまでどおりセッションの間だけ）
- SSH の接続先（表示倍率がない）
- 接続先の編集画面に倍率の項目を足すこと（変えるのはセッションの中だけ）

  - [x] 初めて開く接続先は「画面に合わせる」で始まる（メニューの表示倍率も「画面に合わせる」）
  - [x] メニューで「100%」にして切断し、一覧から開き直すと 100% で始まる（メニューの表示倍率も「100%」）
  - [x] ダブルタップで切り替えた倍率も、開き直したときに引き継がれる
  - [x] 「画面に合わせる」に戻して開き直すと「画面に合わせる」で始まる
  - [x] 設定の「表示」に「初期倍率」がない
- ### 異常系
  - [x] セッションを開いたまま（切断せずに）アプリを終了し、起動し直して開くと、最後の倍率で始まる
  - [x] 接続に失敗した（サーバが止まっている）あと、サーバを起動して開き直しても、覚えた倍率は変わらない
- ### エッジケース

  - [x] 接続先を削除して同じ名前・同じホストで作り直すと「画面に合わせる」で始まる
