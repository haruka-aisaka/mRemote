# セッションのメニューで変えた設定を、その接続先の設定として保存する

## 背景
セッションのメニューで解像度や画質を変えても、そのセッションの間だけで、次に開くと元に戻る。
表示倍率だけは前回の変更で引き継ぐようにしたが、端末の中に別に覚える形で、接続先の編集画面には出ない。
設定によって「残るもの・残らないもの・見えないところに残るもの」が混ざっていて、わかりにくい。

## 現状の挙動
保存先はどれも iPhone の中（Mac 側には何も保存していない）。

| 項目 | セッションのメニューで変えたとき | 接続先の編集画面 |
|---|---|---|
| 表示倍率（画面に合わせる／100%） | 端末の中に接続先ごとに覚え、次回はそれで始まる | 項目がない |
| 解像度 | そのセッションの間だけ | ある（全体設定に従う／自動／固定の大きさ） |
| 画質（Mac のとき） | そのセッションの間だけ | ある |

## 変更後の挙動
**セッションのメニューで変えた「表示倍率・解像度・画質・省データ」は、その接続先の設定に保存する。**
接続先の編集画面に、いま使っている値がそのまま出る。

- 変えた時点で保存する（切断のしかたに関係なく残る）
- 次にその接続先を開くと、保存した値で始まる
- 接続先の編集画面にも同じ値が出て、編集画面で変えれば次の接続からそれになる
- 「全体設定に従う」になっていた項目をメニューで変えると、その値（例:「2848×2004（iPhone Duo）」）に置き換わる。
  全体設定に戻したいときは、編集画面で「全体設定に従う」を選ぶ
- 接続先の編集画面に「表示倍率」（画面に合わせる／100%）を足す。一度も変えていない接続先は「画面に合わせる」
- 「省データ」は別の変更定義書（2026-10-25-data-saver.md）で足す項目。同じルールで保存する
- これまで端末の中に覚えていた表示倍率は、アップデート後の最初の起動で各接続先の設定に移す（見た目の動きは変わらない）
- 同じ接続先を 2 つ同時に開いて別々に変えた場合は、あとで変えた方が残る
- 複製すると、これらの値もそのまま複製先に入る（これまでどおり、接続先の設定はすべて複製される）

## スコープ外
- メニューのほかの項目（画面のタッチ・Windows の拡大率・画面の端まで使う・スクロール方向など）。これらは今のまま
  （端末全体の好み、またはセッションの間だけ）
- 全体設定（設定画面）を変えること
- Mac 側に設定を保存すること

## E2E テストチェックリスト
- ### 正常系
  - [ ] メニューで解像度を 2848×2004 にして切断し、一覧から開き直すと 2848×2004 で始まる（Mac の仮想ディスプレイも 2848×2004）
  - [ ] そのあと接続先の編集画面を開くと、解像度が「2848×2004（iPhone Duo）」になっている
  - [ ] メニューで画質を「低画質・省データ」にして開き直すと、メニューの画質がそのまま
  - [ ] メニューで表示倍率を 100% にすると、編集画面の「表示倍率」も 100% になっている
  - [ ] 編集画面で表示倍率を「画面に合わせる」に変えて保存すると、次の接続は画面に合わせるで始まる
- ### 異常系
  - [ ] 接続に失敗したあとでも、保存した値は変わらない
  - [ ] セッションを開いたまま接続先を削除しても落ちない（メニューで変えても何も保存されない）
- ### エッジケース
  - [ ] 「全体設定に従う」だった解像度をメニューで変えると、編集画面ではその固定の値になる
  - [ ] 以前の版で表示倍率を 100% に覚えていた接続先は、アップデート後も 100% で始まり、編集画面でも 100%
  - [ ] 接続先を複製すると、複製先も同じ解像度・表示倍率・画質で始まる
  - [ ] 「接続先一覧へ戻る（接続を維持）」から戻っても、変えた値のまま
